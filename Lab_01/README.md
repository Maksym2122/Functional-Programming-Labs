## Опис проекту
Програма реалізує чисте обчислювальне ядро для складського обліку:
- Відбір товарів, що потребують дозамовлення (`stock < min_stock`).
- Обчислення необхідної кількості та вартості поповнення з урахуванням політики оптових знижок.
- Дотримання принципів FP: pure functions, immutability, dependency injection, typing.Callable.

## Структура
- `core.py` — чисте обчислювальне ядро.
- `app.py` — оболонка для I/O та виклику ядра.
- `tests/test_core.py` — unit-тести pytest.
