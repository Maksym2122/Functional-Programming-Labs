# Лабораторна робота №1

## Основи функціонального програмування у Python

### Варіант 12 — Складський облік

Програма працює з товарами складу та визначає товари,
які потрібно дозамовити.

Для кожного товару використовуються:

- залишок;
- ціна;
- мінімальний запас;
- категорія.

Програма обчислює кількість товару для поповнення
та загальну вартість поповнення.

## Структура

- `core.py` — чисті функції та функціональне ядро.
- `app.py` — введення, виведення та запуск програми.
- `tests/test_core.py` — pytest-тести.
- `requirements.txt` — залежності.

## Функціональний стиль

У `core.py`:

- немає глобального стану;
- немає `print`;
- не змінюються вхідні списки та словники;
- функції отримують параметри явно;
- результат створюється як новий об'єкт.

Політики дозамовлення та оптової знижки передаються
через `typing.Callable`.
