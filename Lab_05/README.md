# Лабораторна робота №5: Ліниві обчислення, генератори та `itertools` (Варіант 12)

## Ключові принципи реалізації
- **Лінивість (Lazy Evaluation):** елементи обчислюються по одному в міру запиту (`next()`), що дозволяє працювати з нескінченними джерелами (`count`, `fib_stream`, `triangular_numbers`) із константним споживанням пам'яті $O(1)$.
- **Запобігання передчасній матеріалізації:** перетворення потоку у `list` виконується лише на фінальному етапі після обмеження потоку через `take`, `islice` або `takewhile`.
- **Одноразовість генераторів:** після вичерпання генератора повторна ітерація потребує створення нового екземпляра потоку.
