# Лабораторна робота №1

## Основи функціонального програмування у Python

### Варіант 12 — Складський облік

Програма визначає товари, які потрібно дозамовити,
на основі поточного залишку та мінімального запасу.

Для кожного товару зберігаються:
- ID;
- назва;
- залишок;
- ціна;
- мінімальний запас;
- категорія.

Програма обчислює кількість товару для поповнення
та загальну вартість з урахуванням знижки.

## Структура

- core.py — чисті функції та обчислення.
- app.py — запуск програми та виведення результату.
- tests/test_core.py — автоматичні тести.
- requirements.txt — залежності.

## Функціональний стиль

- Вхідні дані не змінюються.
- Глобальний стан відсутній.
- Виведення результату винесено в app.py.
- Політики дозамовлення та знижки передаються через Callable.
- Результат повертається як новий об'єкт.

## Запуск

Встановити залежності:

pip install -r requirements.txt

Запустити програму:

python app.py

Запустити тести:

pytest

Перевірити типи:

mypy core.py app.py tests

Перевірити форматування:

black .

Перевірити код:

ruff check .
