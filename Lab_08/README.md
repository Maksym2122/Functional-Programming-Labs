# Лабораторна робота №8: Алгебраїчні типи даних (Варіант 12)

## Опис моделі
Реалізовано алгебраїчний тип даних (ADT) для представлення ієрархічного дерева меню застосунку:
- `Action` — кінцевий пункт меню з назвою, командою та дозволеними ролями.
- `Submenu` — рекурсивний вузол, що містить кортеж дочірніх елементів `MenuNode`.
- `Separator` — візуальний розділювач пунктів меню.
- `MenuNode = Union[Action, Submenu, Separator]` — рекурсивний тип-сума.
- `Role = Literal["guest", "user", "admin"]` — обмежений набір ролей користувача.
- `HasTitle(Protocol)` — структурний інтерфейс для елементів навігації.
