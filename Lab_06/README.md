# Лабораторна робота №6: Замикання та декоратори як HOF (Варіант 12)

## Тема
Кешування конвертації даних за допомогою замикань (`closures`) та параметризованих декораторів (`@cached`, `@count_calls`, `@timed`).

## Структура проєкту
- `closures.py` — замикання зі збереженням стану через `nonlocal` (`make_counter`), фабрика логера (`make_logger`) та фабрика функцій конвертації (`make_unit_converter`).
- `decorators.py` — параметризовані декоратори `@cached(ttl)` (із підтримкою статистики `cache_stats()`, повного очищення `cache_clear()` та інвалідації за предикатом `cache_invalidate()`), `@count_calls` і `@timed` із інʼєкцією залежностей (`clock`, `time_fn`, `logger`).
- `main.py` — демонстрація композиції декораторів для конвертації показників датчиків.
- `tests/test_lab06.py` — детерміновані `pytest`-тести без реальних затримок.

## Запуск та перевірка
З кореневої директорії репозиторію:
```bash
python -m lab06.main
pytest lab06 -v
mypy lab06
black --check lab06
ruff check lab06
